Compare Browser HTML5 Compatibility: This activity focused on HTML5 browser compatibility and accessibility. By reviewing HTML5 Accessibility, I learned that browsers can differ significantly in how well they support HTML5 features, particularly when accessibility is considered. The comparison showed that Chrome 84 scored 98.5%, Edge 80 scored 100%, Firefox 80 scored 94%, Safari 13 scored 97%, while Internet Explorer 11 scored only 56%. I found it particularly interesting that compatibility is not simply about whether a browser recognizes a feature; accessibility also depends on factors such as keyboard support and how information is communicated to assistive technologies. This reinforced the importance of following web standards when developing websites. I can apply this knowledge in my Web Design and Interactive Media coursework and future web projects by considering browser compatibility and accessibility rather than designing only for how a website appears in one browser. This is especially important given my background in multimedia, where I want digital content to be accessible to as many users as possible.
